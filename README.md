# Product line

The shared standards and architecture decisions behind Marcel Roozekrans's .NET product line. Each product decides its own design in its own repository; what holds for all of them is decided here once.

* **[standards.md](standards.md):** the rules in short, for people and for AI build sessions. Each product's `CLAUDE.md` points to it.
* **[docs/adr](docs/adr/README.md):** the decisions behind those rules, with their context and consequences.

## Products in the line

* AI and governance: AI.Sentinel, Themis.NET, [MagicLink.NET](https://github.com/MarcelRoozekrans/MagicLink.NET), Daedalus.NET, Thalos.NET, Minos.NET, Mnemosyne.NET, Ariadne.NET, Rag.NET.
* Libraries: the [ZeroAlloc libraries](https://github.com/ZeroAlloc-Net), which the other products build on.
